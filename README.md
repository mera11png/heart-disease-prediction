# heart-disease-prediction
 Heart Disease Prediction App using Machine Learning
 **Live Demo:** [Click here to try the app](https://heart-disease-prediction12.streamlit.app/)

## Features
- Age
- Sex
- Dataset (Source): Cleveland, Hungary, Switzerland, VA Long Beach
- Chest Pain Type (cp)
- Resting Blood Pressure (trestbps)
- Cholesterol (chol)
- Fasting Blood Sugar > 120 mg/dl (fbs)
- Resting ECG (restecg)
- Max Heart Rate Achieved (thalch)
- Exercise Induced Angina (exang)
- ST Depression (oldpeak)
- Slope of ST Segment (slope)
- Thalassemia (thal)

## Model
**Algorithm:** K-Nearest Neighbors (KNN, k=10)
**Test Accuracy:** 86.4%

| Metric | Class 0 (No Disease) | Class 1 (Disease) |
|---|---|---|
| Precision | 0.82 | 0.90 |
| Recall | 0.85 | 0.87 |
| F1-Score | 0.84 | 0.88 |
